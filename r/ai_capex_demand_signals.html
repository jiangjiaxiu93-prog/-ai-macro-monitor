"Bull case 确认"组合阈值

满足以下任意 2 个 → 升级 capex bull 立场： - 指标 9 周 token >50T 持续 - 指标 10 SOTA ≥15h - 指标 11 API 价格上涨

"Bear case 确认"组合阈值

满足以下任意 2 个 → 升级 capex bear 立场： - 指标 9 周 token <15T 连续 4 周 - 指标 10 翻倍周期 >9 月（明显减速） - 指标 11 API 价格下降 + rate limit 解除（供给过剩信号）

五、关键 caveat

1. 三个指标都不是 capex 本身的指标 —— 它们是"capex 是否合理"的底层验证·不能替代金融指标 2. OpenRouter 不代表全部 AI 调用 —— Microsoft Copilot / ChatGPT 内部调用 / 直接 API 都不经过 OpenRouter·真实需求是 OpenRouter 数字的 5-10× 3. METR 测的是"复杂任务" 50% 成功率 —— 与"经济价值实际兑现"是两件事·MIT 95% zero return 仍可能成立 4. API rate limit 既可能是需求强也可能是供给弱 —— 单独看会误判·必须与 OpenRouter token 数据交叉验证 5. 本文件不替代股价 / 估值监控 —— 物理需求强不等于股票要涨·Cembalest "应用层股价不涨"反例存在
