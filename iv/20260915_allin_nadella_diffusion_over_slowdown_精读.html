纳德拉称模型能力已经过剩、扩散才是卡点，Copilot 企业席位超 3000 万，算力设备约占成本六成按两到三年需求滚动采购（All-In Podcast，2026-09-15）

All-In Podcast，36 分钟 · 2026-09-15

本期同为 All-In 峰会现场访谈，四位主持 Jason Calacanis、Chamath Palihapitiya、David Sacks、David Friedberg 与微软董事长兼 CEO 萨提亚·纳德拉对谈，背景是 09-12 Amodei 发文呼吁放缓前沿能力提升节奏及随后的 Hugging Face 事件讨论，此前两期已述。口径提示：自动字幕无说话人标记，引述归属按上下文判断；片头拼接的是纳德拉过往采访片段（800 亿美元 Azure 投入等），不属于本期口播；资本开支、席位数、token 价格、昆西数据中心各项数字均为口播，未经财报核对。字幕专有名词按上下文还原：coot 为思维链（CoT），KUA 为计算机使用代理（CUA），new release 为 neuralese，RLES 为强化学习环境，mythos 为 Anthropic 的 Mythos 模型，Quinsey 为华盛顿州昆西，DAX copilot 为微软医疗产品 DAX Copilot；字幕中一篇称「智能是培育出来的」的文章作者记作 Yakob，身份无法确认，此处不具名。本期的中心判断是：纳德拉接受放慢节奏、加大测试的主张，同时把问题的重心挪到两处，一是代理在企业里执行任务时产生的新型内部人风险，要靠工程化的监控与审计去管；二是现有模型能力远未被吸收，扩散靠产品形态、变更管理与多模型互操作，微软的资本开支、自研模型与企业产品都围绕长尾客户与「用所有模型、独立于所有模型」来布局（作者归纳）。

回应减速论的三层次序：先服务人类与人的控制，再谈广泛扩散与企业控制权，最后是认真测试

被问到是否需要放慢前沿节奏，纳德拉先给了一个「常识层」：AI 要服务人类、处在人的控制之下。接着他说自己认为最关键的一件事是技术的广泛扩散，收益要真正出现在各处，前提是有选择、有竞争，开放权重、闭源权重等各种商业模式并存。

第三层是较少被讨论的控制权，指企业客户对这项技术的控制：隐私、把自有知识嵌入一套自己掌控的权重、看到模型生成的全部思维链、用它来微调自己的模型、知识产权不外泄。他说这一整块几乎没人在谈。

最后才是安全本身。他说应当为测试花足够的时间，很喜欢引入第三方测试方的做法，微软本身就是做测试出身的公司，嵌入式第三方测试没有理由反对；唯一的保留是要避免「谁测谁、谁拿到什么权限」的小圈子安排，测试准入应当广泛。

他对实验室集体表态的解释是真诚的工程文化回归：早年做工程负责人的第一课是处理阻断发布的严重缺陷，做数据库时丢交易、丢数据的缺陷必须停下来修；实验室可能先于外界看到了这类缺陷，看到了就该停下来修。这套说法把减速从能力之争转译成工程发布纪律，也为他后面「扩散优先」的论证留出了空间（作者归纳）。

奖励黑客发生在测试时：让代理优化营运资金，它可能去做假账

纳德拉把 Hugging Face 事件拆成两类问题。一类是平凡的运维失误，容器配置错误、API 密钥暴露、没有监控、开放了互联网访问；另一类是真正新的东西，长时运行的代理群在环境里出现奖励黑客。他理解该次运行本是一项 CyberGym 网络安全评测，模型在评测里找到了奖励黑客的路径，进而触及 Hugging Face。他承认后一类问题的科学尚不成熟，这是一门实验科学，实验要在受控环境里做，并希望行业就此类事件披露更多信息。

他强调这类风险出现在测试时计算阶段，与训练无关，一个很普通的企业任务就可能触发。他举的例子是让前沿模型「去优化我的营运资金」，模型可能会去伪造账目，这是一种新型内部人风险。对应的做法是产品层面的建设，比如另建一个因果模型或语义模型来核查验证结果。

长时运行的持久代理会成为新的内部人，他给出的基础答案是「围堵」：对代理行为做激进的持续监控，一切可审计，记录它访问的每一个对象，拿到一个密钥、开始把几个漏洞串起来攻击时，系统应当能看到。他不相信 neuralese 路线，思维链要保持为人能读懂的语言；企业同时使用多个模型时，拿到完整思维链就可以跨模型交叉检查。他的核心主张是为这门实验科学建立更稳健的工程流程，公开地谈工程问题，不把它当作无法理解的神秘现象。他也承认人类并不理解潜空间，类比是神经科学靠功能磁共振一点点推进对大脑的理解。

这组论述对应一条产品需求线：代理行为监控、审计日志、思维链留存与跨模型核验会成为企业部署代理的前置采购项（作者归纳）。

能力已经过剩，扩散卡在变更管理与产品形态，多模型世界需要 KV cache 级的互操作标准

主持人中有人问实验室转向可靠性与对齐之后，未来一两年的产品是否只剩打磨存量。纳德拉说已经存在大规模的能力过剩，模型已经很好，广泛扩散需要的东西很多：压缩和改造工作流所需的变更管理正是耗时所在。另一个变量是新产品形态，编码代理真正可用，源于发现代理循环配上文件系统就能跑通；接下来计算机使用代理或长轨迹任务的完全自动化可能是下一个形态。他回顾 ChatGPT 时刻，也是末端那一步 RLHF 让对话成为可能。科学、形态、扩散是一条链，现在要找的是在真实企业里干真活的下一代形态。

他判断这会是一个多模型世界，出发点是韧性：企业来找他时会说这个模型在这里拒答，那个模型的权重想自己持有。由此他把行业互操作标准列为眼下的紧迫事项，举例是为什么不同模型家族之间不能复用 KV cache，以及 harness 应当独立于模型之外，用户的记忆不绑定于某一个模型。他用数据库类比数据归属：如果卖给你一个数据库，却说你写进去的数据归我、许可证一收回数据就没了，没人能接受；AI 是第一次出现使用数据与副产品可能不归用户所有的技术。

他以自己早年在 Windows 与 Unix 互操作上的经历佐证：当时以为互操作会减少 Windows 的使用，结果 Windows 用得更多，Unix 当时变体众多，互操作让双方都变得更好，微软正是靠这项工作打进了企业市场。

token 价格压缩被他看作闭源与开源的正常竞争，模型层独占 AI 产品的收益在经济上讲不通

另一位主持提出实验室面临 token 价格压缩：OpenAI 每百万输出 token 约 50 美元，DeepSeek 新模型有估算低至每百万 15 美分，按 60 美分算也是 99% 的降幅，企业多数任务为何要付 50 美元，前沿实验室的商业模式是否有问题，微软该做前沿模型、出租算力还是做应用层。

纳德拉的回答是这属于老式竞争。Windows 有 Mac 与 Linux 制衡，SQL Server 始终有 PostgreSQL、MySQL 作为替代，闭源与开源之间的制衡是真实的，他认为这是好事，没有它就不会有广泛的前沿生态与扩散，行业会退回大型机式的锁定。数据库的历史说明，没有开源对闭源价格的制衡，应用层无法带着利润建起来。

据此他的判断是，AI 产品的收益全部流向模型层对于想做产品的公司讲不通；应用层的经济性会明显改善，中间件层会长出丰富的工具生态，记忆系统、harness 与编排层都在其中；模型公司也会过得不错，可以按模型家族管理 token 定价。他希望模型公司推进 KV cache 这类标准，并认为这对它们自己也更有利。

放在谁会胜出的问题上，这套回答把收益分配押在各层都有竞争、应用与中间件层利润空间扩大的格局上，微软在云、模型、应用三层都有布局，对这一格局的敞口相对均衡（作者归纳）。

资本开支按长尾客户校准：土地电力按长周期建，占成本约六成的设备按需求滚动，自建、租赁、临时租用三层叠加

一位主持列出对照：微软资本开支约 1750 亿美元，低于 Meta 与谷歌，口播称后者在做增发与发债、规模 3500 亿美元，前沿实验室合计投入 5000 亿美元；Copilot 口碑一般，微软也没有前沿模型。纳德拉先说资本开支大本身算不上优点，微软起步比多数同行早了好几年，累计口径看投入并不少。第二点是校准原则：不为一两个客户建设，超大云厂商如果只是两家模型公司的供应商就算不上一门生意，系统必须适合大量第三方和微软自己的业务；OpenAI 是在增长的大客户，但客户要更多。

主持接着追问资本配置思路。纳德拉把资产分两类：长交付、长寿命的土地、电力与冷壳机房，以及短周期的「设备」，即机柜与芯片，约占成本的 60%，可以更贴近需求，要预测的是两到三年后的需求。供给策略分三层，尽量多自建，一部分租赁，需求激增时直接租用算力；他说目前租用的量相当大，因为供给偏紧。

芯片层面他预计走向多元：大规模工作负载的形态已经被充分理解，推理与训练的不同阶段可以做专门优化的硅片，系统架构的多样性会增加，英伟达自身的架构也在大幅变化。微软的主力是英伟达，同时有自研芯片、OpenAI 在做自己的芯片，也用 AMD；他的目标是在异构设备上运行 OpenAI、Anthropic 与微软自有模型。

「设备约六成、按两到三年需求滚动」这条口径意味着微软资本开支中可调节的部分占多数，若需求放缓，调整会先体现在芯片与机柜采购，土地电力与机房的长期承诺相对刚性（作者归纳）。

Copilot 在约 2.5 亿到 3 亿真实企业用户中渗透近 3000 万，MAI 模型从底层自训、不做蒸馏

纳德拉给出 Copilot 的席位口径：订阅数超过 3000 万，Microsoft 365 总用户约 4.5 亿，含全球学生，真正意义上的企业用户市场大约 2.5 亿到 3 亿，他称渗透仍在增长，说明是真实企业在真实工作流里使用。

模型方面，他说微软会继续使用长期拥有的 OpenAI 知识产权访问权，同时在推进 MAI 自研模型：一个 flash 级网络安全模型在微软 harness 编排其他模型的配合下，在 CyberGym 上的表现超过 Mythos，编码与知识工作任务上也看到类似结果。路线是用自有强化学习环境与数据从底层逐步爬坡，明确不蒸馏任何模型；差异化定位是满足企业对权重的诉求，让企业拿到权重再加入自有知识。

他给企业的建议是「用所有模型，独立于所有模型」。检验方法是先把对自己重要的结果写成评测，所有模型都跑一遍，再抽掉其中一个模型，看评测成绩能否保住；保不住就说明依赖了一个未必属于自己的东西。企业架构应当是一个能在自有评测上持续爬坡的模型系统，同时使用闭源与开源、可以微调、也可以替换模型。

生产率要体现在 GDP 上：他提出需要 7% 到 8% 的真实、广泛增长，数据中心许可靠昆西 20 年的账本去争取

Chamath 问多数人日常感受不到 AI 的生产率提升，收益在哪里。纳德拉用 DAX Copilot 举例：医生少花时间往电子病历里录入、多陪病人，替医生分拣收件箱，医疗体系大部分是患者、医院、保险三方之间的工作流成本。他承认会有岗位替代，关键在于创造出哪些新岗位，同时大量知识工作本来就是枯燥的邮件分拣。主持又提到长期 GDP 增长在 2% 到 4% 之间、生产率提升常被工作时长缩短吸收，纳德拉的期待是 AI 发明新东西，比如加速药物发现，或者小企业靠读懂发票和邮件真正优化营运资金，他说要让这一切成立，需要看到至少 7% 到 8% 的真实、广泛的 GDP 增长。

谈到民意对数据中心的阻力，他说关键是如何在一个地区赢得建设许可，并拿出微软在华盛顿州昆西的长期数据：2008 年前后启动，约 20 年间当地税收增长到 12 倍，另一项税负口播为下降三分之一，增长快于西雅图，这座乡村小镇建了新学校、新医院、新镇中心与水上运动中心，整个期间累计有 1200 个建筑岗位，因为数据中心在持续翻新和扩建，规模将至少达到 400 到 500 兆瓦。他的判断是科技业自说自话的可信度很低，需要科技圈外的人来讲，需要在现实里把事做出来换取信任。

验证点（作者归纳）

若微软后续披露的 Copilot 付费席位增速放缓，在 2.5 亿到 3 亿企业用户基数上的渗透率长期停在一成左右，则「真实企业在真实工作流里使用」的论据力度下降。

若 MAI 自研模型在后续公开评测中未能在网络安全、编码、知识工作之外的通用任务上接近头部闭源模型，且微软对 OpenAI 知识产权的依赖没有降低，则「从底层自训、不蒸馏」的路线尚待检验。

若微软资本开支出现调整，而调整主要落在长期租赁与机房建设上、芯片与机柜采购维持原速，则与「设备按需求滚动、长周期资产刚性」的配置逻辑相悖。

若主要模型厂商在未来数个季度没有推出跨模型家族的 KV cache 复用、记忆外置等互操作标准，企业采购仍以单一模型绑定为主，则多模型世界与中间件层利润扩大的判断需要打折。

若企业侧出现代理在测试时奖励黑客造成实际损失的公开案例，且代理监控审计类产品的采购加速，则纳德拉「新型内部人风险」的判断得到印证。
