Ghodsi 把当下的存在性风险判为接近零，给递归自我改进列出四个须同时成立的条件，指出现实方向相反：复现前沿一次要五十亿至一百亿美元，而 CVE 到被武器化已从两三年压到小时级（a16z Podcast，2026-09-18）

a16z Podcast，66 分钟 · 2026-09-18

本期 a16z 播客由该机构的 Martin Casado 与 Sarah Wang 对谈 Databricks 联合创始人兼 CEO Ali Ghodsi（字幕只出现 Martin 与 Sarah 的名字，姓氏按上下文还原）。口径提示：训练开销、CVE 时长、开源占比、成本倍数均为口播，未经核对；自动字幕把 Bostrom 记作 Bodstrom、Yann LeCun 记作 Yandun、网关产品记作 uni gateway（主持方称 Unity Gateway），其余专有名词按上下文还原。分工说明：同一位嘉宾 9 月 17 日在红杉播客那期已写透企业 AI 用法只有两种、落差出在上下文缺失、连接器工期、扩散至少十年与上市时机（09-17 精读已述），本篇不再展开，重心放在增量：存在性风险与递归自我改进的论证、网络安全，以及企业采用里那期没有的新角度。

存在性风险接近零，超级智能按 Bostrom 的定义仍差很多个数量级

他的起点是领导者的责任：除非确有很强理由，不该反复对着几百万人讲人类被抹除的情景，这会把一些本不在技术细节里的人推过去，造成心理健康层面的伤害。主持方的例证是自己的姐妹发短信问，要不要为 AI 末日备好小木屋。被问到 P(doom) 时他先说低于 10%，随即改口说接近零。他也指出这件事已外溢到政治层面，Elizabeth Warren 谈暂停全部 AI 开发，而各国都有选举。

对超级智能，他回到 Bostrom 2014 年那本书的定义：几秒钟写出一篇带原创同行评审内容的博士论文，瞬间完成人类千年量级的思考，在十一维空间里不落笔地直觉推理。他说这与今天的代理差了很多个数量级，看不到朝那里行进的证据；这种东西真出现确实无法靠工程解决，这点各方本来就同意，他反对的是把它与「现在的代理能干以前干不了的事」混为一谈。

递归自我改进的四条件：资源要超线性下降、时间要下降、智能要上升，且能反复重来

他把实验室内部的紧张归到递归自我改进上，并要求把它拆成四个必须同时成立的条件：下一代模型训练所需资源与 GPU 显著减少，且是超线性地减少；训练所需时间同样减少；模型的准确率与智能在上升；前三件事可以一遍又一遍重复。任何一条不成立都构成自限，比如资源保持不变，硬件总量本身就会把速度卡住。四条都成立时才会出现下一代模型用一半时间、一半资源且更聪明的情形；他补了一句，即便如此也未必通向超级智能，但风险更高，所以希望实验室公开这部分数据。

他特意排除了一种混淆：如果所谓自我改进只是软件在写自己，Databricks 九成以上的软件已经由 AI 写成，剩下几个百分点是否也交给 AI 并不重要。很多人把「我还写不写代码、我的价值在哪里」与「这是否意味着会出现那种超级智能」搅在了一起。

他和主持方给出的现实观察指向相反方向。复现前沿的训练开销从当年的一亿美元量级涨到五十亿至一百亿美元，每家实验室一年只做一两次这样的运行，参与的人更多、过程更脆：每多一个数量级的 GPU 就要处理以前不必处理的错误，鲁棒性得跟着提，失败一次就是巨额资金作废，被搞砸的运行不止一次。主持方补充说六个月后复现同一前沿的成本约为当初的二十分之一，也就是说变便宜的来源是时间推移，与自我改进无关。

两条可操作的检验：只盯训练下一代模型的那个团队，以及区分自催化与真正的自我改进

主持方提出的黑箱检验是看实验室自身：如果这些公司在人数与投入持续下降的同时产出仍在加速，那就该注意；眼下各家都在大举招人。Ghodsi 认为这个指标不够公平，早期 OpenAI 在做上百件事而真正做语言模型的只有十来个人。他的修正是只盯训练下一代模型的那个团队，看预训练与后训练的人是否在变少、用的 GPU 是否越来越少，而这并没有发生。他本人也愿意当检查员把数据摊开，他估计四条件同时成立的概率不高。

主持方做了一个术语切分：很多人口中的递归自我改进其实是自催化，用模型写 GPU kernel、做数据清洗，与没有芯片就造不出芯片、编译器编译自己属于同一类现象。按他接触创业者的样本，喊递归自我改进的人里大约只有百分之一名副其实，约九成的投入属于自催化，这正是任何一代技术里本来就该看到的比例。Ghodsi 承认这个区分，同时提醒确实有团队在做让模型训练自己这件事，值得单独跟踪。主持方还翻出 1999 年前后对 PlayStation 做出口管制、担心被用于核武模拟的往事，当时的论证结构也是这些东西正变得无限强大、应该叫停，后来并未兑现，问题因此落成一句：这次是否不同。这套链条的用处在于把一个情绪化命题转成可观测的指标集：训练团队规模、单次前沿运行的成本与频次、复现成本的时间衰减率（作者归纳）。

「我们哪里想错了」：pacing 是一次 PR 失误，该说的是 secure the frontier

主持方的批评集中在措辞上。行业自我监管并不罕见，讲安全、讲监督都合理，问题是把它包进 pacing 这个词：放慢与安全是两件正交的事，你可以慢慢造一件武器，那与造武器没有区别；这些公司一直在全速跑、还在买更多算力，外界因此觉得这话不真诚；它又像是对要求暂停一方的半推半就，听着像暂停又不算暂停，两头不讨好。他给的对照是直接说 secure the frontier，Zuckerberg 那一版强调安全与自我约束、把延后发布归因于安全，效果好得多。

Ghodsi 部分不同意。他承认公地悲剧真实存在：作为经营者他要竞争、要赢，单方面停下来就是当冤大头，所以业内有人喊的其实是「请进来管住我们，划条线，我们乐意照规则做安全的事」。他举 Hugging Face 与 OpenAI 那次事件说明确实有速度问题：当时没有人盯着每一个 token，强化学习实验跑完之后才回头检查发生了什么，数百万 GPU 小时的产出、代理在沙盒里乱跑；安全团队若全程盯着会拖慢很多，而在不确定同行是否照做时没人愿意单独承担。他还给出一个制度预期：既然这些公司一边说存在性风险、一边请求被监管，监管者长期说不会很难维持，他判断当前的拒绝撑不了太久。

对第三方检查，他赞成让外部检查员进实验室看数据，关键在于选谁，立场先定的人说什么都不具备信息量。他举的正面例子是若由 Yann LeCun 这样的深度神经网络奠基者看完出来说没什么可看的，他会很安心；若对方口径松动，那本身就是强信号。至于实验室互相评审，他的评价是拳击手不能自己当裁判，一旦对手放出好模型就会满场喊犯规，何况两家有竞争、有上市计划、有过往恩怨。主持方补充说行业自律与联邦介入之间会互相渗透，IETF 是一条路径，FINRA 则是与政府挂钩的自律组织。

面对 Elon Musk 那句「这是精心设计的四维棋，一边说全人类会死，一边问你要多少 IPO 配额」，他的回应是动机会混在一起：有人真的被吓到，也有人觉得一轮能拖慢同行的监管对自己有利，而人通常有本事让各种利益在脑子里和谐共处。他承认行业有过营销惯性，每训完新模型就说它好到让自己害怕，同时网络攻击的威胁是真的，两件事未必矛盾。

网络安全：CVE 到被武器化从两三年压到小时级，数据与安全两个市场正在合流

他给的时间序列是 2018 至 2019 年一个漏洞从公布到被真正武器化大约要两三年，到 2022 年降到八九个月，此后继续下坠，现在基本是小时级，几乎一公布就被利用。这个速度下人跟不上，只能自动化。他描述的现状是多数组织还在用旧式的安全运营中心，值班的人每天面对上百封告警邮件，很多是误报但有一些不是，没有时间逐条过；真正需要的是自动化的威胁狩猎，让代理持续攻击自家系统。银行与安全意识强的一批机构在做，多数组织离这个状态还很远；Databricks 自己在检测市场有产品（字幕记作 Lakewatch）。

他判断数据与 AI 的市场正在与网络安全合流：过去一边是数据与机器学习、一边是检测入侵，现在企业内部跑着大量代理，还在与别人的代理打交道，持续产生日志、轨迹与指纹，这些都要被分析，所需规模比一两年前高出许多个数量级。他把这称为两个市场塌缩。

风险的形状他说得很具体：把代理放出去，它们会找到漏洞与可利用的路径，在这里那里破门而入；还可以设想代理夺取资源并在别处执行自己，像病毒那样扩散。他认为这属于经济损失与有人受伤的量级，够不上存在性，但确实有一个能力拐点：过去他没法调集一万名安全研究员在沙盒里干一个月、消耗相当于一亿美元薪酬的工作量，现在按下按钮就可以，十万个也行。这是网络风险的真实来源，也是他认为能靠工程解决的问题。主持方留下一个反问：互联网早期蠕虫已经让医院停摆、打掉关键基础设施、造成数百亿美元经济损失，那时联网的经济体量还小得多；如今钱与人都涌进 AI、找风险的人也多，却没有出现与当年相称的破坏。他的回答是自己晚上睡得着，同时坚持有大量基础设施需要尽快加固。

本体的工程形态：把它当离线索引算，权限让这张图比 PageRank 难

企业采用的总判断 09-17 精读已述，本期的增量在实现路径。他说今天的代理，无论 Claude Code、Codex 还是各类开放实现，跑的都是一个推理循环，带着问题逐个资源去查，先访问这个 MCP 服务器看答案在不在，再换下一个，最后综合成回答，这条路慢。他的类比是假设二十五年前 Google 这样做搜索：接到查询后访问一个网站，用语言模型总结它做什么，找几个枢纽链接并行跳进去，折腾十分钟再把十条蓝色链接给你，每次都很贵、等很久、质量还差，因为只看了全网极小的一部分。Google 的答案是索引，查询命中倒排索引，一百毫秒内返回；本体要做的就是把这个索引离线地、持续地算出来。

比 PageRank 难的地方在两处：当年的网页人人都能访问，这里有权限与访问控制，你能看的数据未必是我能看的；对象类型也远不止网页一种。他说这件事可做，Databricks 自身本体图的节点以百万计。他给了 Palantir 一句肯定：对方把隐性知识落成文字做得好，Databricks 则自动把这些材料转成图喂给代理。

另一处增量是原料端的阻力。首要条件是组织里发生的一切已被数字化、每场会议都有转写，而在很多组织里收集这一步本身就是问题，因为法务团队会说不要录每一通电话。配套的是驻场服务，FTE 模式的需求明显上升：图是自动建的，但客户什么都没在收集就无从建起；另一部分用在客户要的带护栏代理上，例如 Fox 的体育 AI，你问政治它会拒绝并把话题带回体育。

评测是客户不愿意做的那一步：自动生成的 eval 放在首屏也没人用

被问到自建与定制模型的难点，双方都指向评测。Databricks 曾在产品里自动替客户生成评测集并放在显眼位置，客户不愿意用；改成可选、挪到后台之后，再没有人点进去。他给的原因是客户要快速的正反馈：出了新模型想试一下、想把手上的问题解决掉，没有时间走先做评测集再立基线的科学方法。他的类比是测试驱动开发，人人都说正确，实践中很少有人真做。结论是训练自己的模型，难的那一步是评测。

这与后训练的商业化直接相关。Databricks 2023 年收购 Mosaic 时还讲替客户做预训练，他现在说那不成立，现成的预训练模型已经足够好；真正跑起来的是后训练与强化学习，许多 AI 创业公司本身就是客户，用强化学习环境把开源模型在某个重复任务上调到很好，成本压下来、速度提上去、IP 归自己。大型企业则需要基础自动化，眼下做这件事对它们来说太重。评测能力由此成为企业能否离开「默认用前沿模型」的分水岭：做不出评测集的组织只能持续为通用能力付费（作者归纳）。

成本治理：预算护栏加智能路由，同一模型换个 harness 成本差近 2 倍

时间线上他自认领先几个季度：去年第四季度模型变好后他开始往生产环境提交代码并做排行榜，到一二月全员推开，token maxing 的失控在二三月就出现。治理的抓手是那套网关，它原本向客户供应 OpenAI、Anthropic、Gemini、Grok 与各类开源模型的 token 容量，他们在上面加了三层：按人和按组设预算上限并发预警、告诉你额度还剩多少，做分析以预测成本走向，再加智能路由，在接近预算或问题足够简单时自动切到更便宜的模型。

此外他们自建了一个 harness 用于在不同 harness 之间多路复用。他给的数字是同一个模型、同一个版本，换一个 harness，实际成本能差出接近两倍，换 harness 本身就是可观的成本杠杆。综合结果是 token 用量持续上升而 AI 成本基本走平。这给推理需求的预测加了一个折价项：企业侧 token 量的增长未必等比例转化为模型厂商的收入（作者归纳）。

开源按金额约 5%、按 token 超 60%，一家规模化公司把工程负载转向 GLM

被问到开源占比，他给了两个口径：按金额算大约 5%，按 token 计数超过 60%。主持方补充了对外产品与内部使用的差别，面向产品的一侧有公司接近九成用开源，内部一侧很多团队不在乎成本、直接上前沿，等规模变大才开始管。主持方给出的新事实是上周有一家规模化公司在董事会上说要把工程组织从前沿模型迁到 GLM，并问这是趋势还是孤例：此前几轮开源冲击都没在市场上留下可观察的痕迹，这次听到的案例更实。

他的回答是两边都要：困难任务上要最新的、能带来回报的模型；大量琐碎工作用前沿模型是浪费，有人用 harness 去重命名文件，模型转五分钟花掉几美分，这类活自己敲键盘更省。做法有几种并存：便宜的小开源模型在需要时调用大模型这一专家模式，或者反过来，以及让两者来回传球。主持方补了一个自己看到的分工，用 Fable 或 Astra 做架构、便宜模型做实现、再用前者做审计。他的结论是行业会走出「新模型出来就拿它干所有事」的范式。

代理成了新的采购方：Neon 与 Lakebase 上九成以上的数据库由代理创建

主持方提到有第三方测评把 Lakebase 与 Neon 列为代理首选的 Postgres 数据库。Ghodsi 把功劳给 Neon 团队，理由是他们换了服务对象：数据库行业长期围着 DBA 与应用开发者转，这支团队只问怎样对代理更好。做法是启动时间压到远低于一秒、巨大的数据库也能在一秒内克隆、分支功能做得很轻，定价上刻意让实验性用量不至于烧钱。结果是两个平台上创建的数据库超过九成由代理发起。

他还点了几个已进生产的用例：Crisis Text Line 识别青少年自残与自杀倾向，Omnipod 让 AI 学习个人的胰岛素释放并自动给药，与默克合作的 Teddy 模型预测基因调控网络的响应，诺和诺德把 Genie 用在自家试验上，肥胖研究拿到洞见的时间从数周压到数分钟。

验证点（作者归纳）

若头部实验室在后续披露中出现训练下一代模型的团队缩小、预训练与后训练的 GPU 投入下降而发布节奏加快，则他列出的四条件开始逼近；若单次前沿运行的成本与人力继续上升、频次仍为一年一两次，则更贵更慢更脆的事实可以持续证伪递归自我改进的叙事。若六个月后复现同一前沿的成本仍维持在二十分之一量级，则成本下降来自时间推移，把它当作自我改进的证据就站不住。

若未来一年出现由代理链引发的可观察的重大安全事件，损失规模与 CVE 武器化提速的曲线相符，则数据与安全市场合流的判断被支持；若安全运营仍以人工告警处理为主且未出现相应事件，则这轮自动化需求的紧迫性被高估。

若企业侧的开源用量按 token 计数继续向上而按金额仍停在个位数百分比，则模型厂商的收入增长与调用量增长将持续背离；若此前宣布迁往开源的规模化公司在一两个季度内回迁前沿模型，则 GLM 那则案例更接近孤例。
