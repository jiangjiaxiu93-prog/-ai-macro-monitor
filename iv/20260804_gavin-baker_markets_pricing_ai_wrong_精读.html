Gavin Baker：市场对 AI 的定价错在哪（Invest Like The Best，2026-08-04）

Invest Like The Best · 79 分钟 · 2026-08-04

科技股投资人 Gavin Baker 时隔两个月再次做客 Invest Like The Best，录制地点在 Benchmark 的办公室。七月 AI 相关股票大幅回撤，不少名字从高点直线回落四到六成，他把这个月形容为“把 2022 年浓缩进一个月”，随后花一整周在硅谷求证，想找一个能证明基本面在恶化的量化指标，没有找到。这期他把市场依次交易过的每条利空拆开讲了一遍，指出哪些是误读、哪一条真实存在，并交代了自己会在什么条件下改变看法。

一、七月是怎么跌下来的

起点是 Meta 宣布对外出租算力，被读成产能过剩、要砍资本开支。他说财报里资本开支没有砍，他掌握的渠道信息一点没变；真实动机更可能是 Meta 看到 SpaceX 把训练优化过的大集群按远高于合约价的水平卖进市场，想先用一小块产能做出漂亮的 IRR 再去融资加码。第二条是开源：GLM 5.2 和 Kimi K3 之后 Silicon Data 的 token 指数回落走平，他说这个指数反映的是结构而非总量：需求从推理毛利八九成的前沿 token 切向便宜的开源 token，指数会往下走，算力消耗并没有少。第三条是中国拿到 DUV 光刻机带崩半导体设备股，他说 DUV 之于 EUV 相当于螺旋桨飞机之于喷气发动机，从无到有是一次相变，不该轻描淡写，但落后二十多年，制程要靠反复做才学得会，即便影响到 ASML 订单也可能是五年后。

只有第四条他承认是真的：实际利率上行、信用利差走阔、Meta 新债没有定在人们以为的位置、各家 CDS 普遍走阔。如果这轮建设要靠债融资，就是实打实的利空。

我想被吓到。我不想在这些股票越跌越便宜、我却觉得预期回报在上升的时候，觉得自己像个疯子。

这是他这趟去硅谷的动机。他还注意到市场解读正被同质化，因为所有人拿到消息第一件事是扔给 Claude。

Claude 差不多是股市的克朗凯特，所有人都信它说的。

他借 Mauboussin 的说法，把这种一致性看作多样性崩塌。

二、算力现货价还在涨

他这一周问所有人的问题只有一个：有没有一个负面的量化指标。他说没找到，GPU 租赁价格、DRAM 现货价、token 增速怎么切都在加速；唯一被提到的负面是第三方数据显示 Anthropic 的曲线略偏离原轨迹，但 OpenAI 和开源加速更快，合起来是净加速。

更有说服力的是价格。2024、2025 年再乐观的人也只预期老 GPU 租赁价缓慢下行，没人想过 2026 年会往上走。他当天早上聊过的一家创业公司，几千张 B200 的集群原来签的是每 GPU 每小时两美元多，七个月后续租同样规模配置的集群，希望能压在四美元以内；另有一家推理云公开说，合约到期后准备为 Blackwell 付翻倍的价格。含义是已装机算力的合约价相对现货大幅折价，到期后会被重新定价上去，即便现货回落也成立，也就是超大规模厂商现在在少赚。佐证是微软、Meta、亚马逊已披露的经营性现金流增速从 28 升到 32，剔掉这个季度异常多的一次性项目是 28 到 35；而微软六月才上的产能还没体现在二季度，Rubin 还没按溢价出货，合约重定价更没开始。

他说录制当天英伟达的远期市盈率是过去十年的低点，半导体股更便宜的时候只有“解放日”和 DeepSeek 那两次。市场显然认定这些公司在赚超额利润，他说也许市场是对的，投资里最重要的三个词不是“安全边际”，而是“我不知道”。

三、这轮扩张要不要举债

债务驱动的建设之所以危险，是因为债要立刻还，供需稍有失衡就迅速瓦解，互联网那一轮就是这么结束的，所以这个月他下功夫最多的是信用。结论建立在一个观察上：卖方模型里未来要上的 Blackwell 和 Rubin 吉瓦，大致按落后两代的 Ampere 变现速率在算，对应超大规模厂商 1.3 万亿到 1.4 万亿美元经营性现金流；如果按低于当前 Blackwell 但明显高于 Ampere 的水平变现，就接近 2 万亿，差额大约把 7000 亿美元的信用需求拿掉（他没有说明这是哪段时间的累计口径）。他还给了一个反向说法：即便建设确实需要信用，如果信用不到位，那就意味着已经存在的算力更值钱。

他两期之前担心过 Blackwell 的空档期——几千亿美元的芯片先用于训练，训练本身不产生回报，一季度确实看到了；市场在四、五、六月都看过去，偏偏七月不看，而这恰恰是经营性现金流开始加速的时候。

四、开源抢份额不等于利空

一个 token 就是一个 token。

产出一个 token 需要的浮点运算、内存、瓦数都一样，所以开源抢走的是前沿模型那层的毛利而不是算力需求，价格下来还带来弹性；开源模型和前沿实验室跑在同一批云上、为算力付同样的钱，利润只是从模型层转移到基础设施层。他反问，如果开源对英伟达不利，Jensen 有什么理由把它做成自己的招牌议题。

机制是路由。很多公司发现 AI 支出翻了二十倍、三个月烧完预算，于是用自己的数据微调开源模型，先走自己的模型再让前沿模型检查，不少场景下效果略好而成本减半——省下的钱来自毛利率从九成降到三成左右，不是来自更少的算力，实际消耗的 GPU 小时反而可能上升。Fireworks 的 Nexus 把这件事做成了三行代码。他也留了另一面：如果前沿模型做到递归自我改进、在每个智能档位的服务成本都大幅下降，开源可能就没位置；他说这不能排除，只是可能性不高，因为不少 AI 原生公司已积累本领域的专有数据。反过来看，便宜的“120 分智商”模型越多，能调度它们的“160 分智商”模型就越值钱。

五、需求从哪来，长约怎么锁

他反复回到一个数字：现在全球用上 agentic AI 的可能就五十万人，而算力已是急性短缺，变成一亿、五亿时会怎样。钱只能来自两处：更快的增长，或对劳动的替代。知识工作的盘子约 25 万亿美元，AI 用得最深的公司里 token 支出占总薪酬已到两成到两成五，他知道一家在三成，也听过五成，按两成推是 5 万亿美元。他说人类当然希望这笔钱来自增长；他看到的替代是少招人而非裁人，一位技术 CEO 告诉他，剔掉疫情期间的超额招聘，创始人控制的公司基本没有大规模裁员。他也提到 Cognition、Ramp、Stripe 的数据显示 AI 支出高的公司增长更快，但承认这些数据没有控制行业结构。

供给侧锁在长约上。内存是关键变量，给定算力配的内存越多、产出的 token 越多，等于降成本，所以内存需求至今没有负弹性。有规模的买家只有四个——亚马逊的 Trainium、谷歌的 TPU、AMD，以及体量超过其余几家之和的英伟达；未来几年的份额很大程度由供应链分配决定，毁约压价一旦碰上周期反转、议价权回到内存厂，下一轮拿不到配额就等于出局。英伟达的新做法他称为“信用包装”加价格地板之上的收入分成，不是自己借钱给客户，而是别人放贷、它拿分成，他认为市场严重误解了这件事。

六、风险清单与几处分歧

他列的第一风险是监管，纽约的数据中心暂停令在他看来是第一个而非最后一个。他说行业公关做得很差，普通人听到的版本是数据中心推高电价、耗光水、抢走工作；而按现在签的条件，数据中心落地往往因表后交易让周边电价下降，开发商还要建学校和消防站，蓝领岗位也不是一次性的。用水那条他说某本书高估了一万倍，作者已多次承认，但错误传得比更正快。

第二个是技术：不少人觉得持续学习和样本效率快被解决了，如果真解决，训练需求可能出现一次断层——现在训练用的是 300 万亿 token 量级，一个人一生大概 200 亿 token 量级，如果十万亿 token 训完就能放出去自己学，训练在算力需求中的占比会收敛到很小。他说这对世界是好事，也很难相信对基础设施需求是净负面，但不想排除；SSI 说八月会发布模型。第三个是价格：如果 GPU 价格持续大幅回落，或几家实验室加开源的需求见顶，他会改变看法；他反问，你听到过谁说自己 GPU 太多吗。

分歧集中在 SpaceX：纽约有大型对冲基金做空，逻辑是算力现货价会跌九成、上这么多算力赚不到那么多钱。他的看法相反：Grok 4.5 和 Cursor 加起来的 ARR 会较快到 100 亿美元级别，至今一年新增供电超过 500 兆瓦的只有超大规模厂商、CoreWeave、Crusoe 和 SpaceX，而它上得最快、成本最低。一份公开报告说它打算 18 个月上 8 吉瓦，他说自己几乎不信这个数字，也从不押注 Elon 做不到，并引用了后者那句“我们擅长把不可能的事做成迟到的事”。
