推理成本的三层供给侧杠杆：一位前英伟达内核工程师的成本压缩路径（Invest Like The Best，2026-08-25）

Invest Like The Best · 83 分钟 · 2026-08-25

嘉宾为前英伟达 GPU 内核与软件性能工程师，2016 年入职，参与第一代张量计算单元争取芯片面积的过程，现经营一家推理服务公司。首先校准标题口径：嘉宾全程未使用"一千倍"这一表述，亦未给出时间跨度，该数字来自末段的一处算例，详见第六节。本期的分析价值在于将"推理成本仍有多少下降空间"拆解为软件、芯片、电力三层可操作杠杆，并给出各层的量化区间。

一、业务定位：以后台长时程任务为目标市场

嘉宾对现有推理服务商的判断是，其资源集中于低延迟场景，方向由一家权重较高的客户塑造。其认为该选择在一年前成立，约六个月前起，需求重心已转向任务持续性与长时程运行。

对"延迟越低越好"的质疑，其回应为：等待状态下的延迟诉求成立，而目标是消除等待环节本身——工作在夜间完成，用户在提出需求前即已交付。更关键的论点是，在反复提示与等待的交互模式下，约束条件为使用者本人的注意力带宽。其主张智能体应运行于人类的时间尺度，管理频率参照同事而非工具。

该判断的支撑为测试时计算扩展，即延长运行时间可提升输出质量。嘉宾称该方向的可下注时点始于上一代长时程模型。份额判断为：今年底后台与实时任务约各占一半，长期趋向九比一（口径未定义）。其对该市场的核心论点为需求无上界——回路中无人参与，后台消耗不受注意力约束。

适配后台的三类任务：深度研究，源数量级在万级以上；网络安全，论证为可生成代码的规模与破坏路径的规模呈指数关系，且能力前沿呈参差状态，大模型可发现的缺陷并非小模型的超集，该特征支持多模型广泛采样；以及个人侧常驻助理，前提条件为单位成本足够低，即"在无回报承诺的条件下仍愿意消耗 token"。

业务边界方面，其明确限定于可验证问题——软件、形式化数学证明及部分科学发现。该类问题当前均隐含一个美元成本，即"可调动多少 token 使结论成立"。不可验证部分（其归入人类品味范畴）不纳入业务。

二、第一层杠杆：软件层，将硬件推至物理极限

嘉宾的优化顺序为软件、硬件、电力，起点为现有芯片与数据中心的剩余效率。

其从原任职机构继承的核心方法论为"光速"标准，即以硬件物理极限为目标值，逐一击穿中间瓶颈，考核对象为绝对数值而非相对竞品的位置。

关于内核工程的剩余空间，其判断为市场普遍高估了该领域的完成度。当代架构建立在既有的注意力优化工作之上，但模型架构的任何偏移（如位置编码方式变更）都会导致既有内核失配。其引述该领域开创者的方法论转变：由手写内核转为"在白板上写内核"，即人负责概念设计与策略描述，模型负责实现。

嘉宾据此承认了对自身不利的一项判断：软件层优势将被抹平。模型能力提升会整体抬高该环节的水位，不构成长期壁垒。这也是其向硬件与电力层延伸的原因。

效率坐标方面，其给出的分层判断为：在大维度矩阵乘运算下，硬件利用率可达峰值的 70% 至 80%，此时约束条件已由软件转为功耗；但实际负载中，多数时间并不处于该运算模式，故其工作重心在于持续以大批量任务填充计算单元。其同时指出编程单位的转变：由单卡优化转向以整机柜乃至整集群为单位。

三、延迟与吞吐的取舍及其硬件含义

物理层面的判断为：GPU 属吞吐导向架构，而过去两年的交互式使用形态将行业整体推向延迟导向。取舍的根源在批处理——批量规模决定并行度，同时使单个请求承担他人流量的等待成本。嘉宾的类比为公共交通与出租车的路径差异，其业务定位为前者。

该取舍直接决定芯片选型策略。GPU 间高速互联的作用是压低单次操作的最小延迟，但其扩展呈次线性——八分片仅得四至五倍加速，损耗来自通信开销与分块效率下降。据此，对低延迟诉求较弱的服务商而言，互联能力较弱但基础算力性价比更优的芯片具备使用价值。其优化目标为单位成本算力，而非延迟指标。

对采用大容量片上静态存储路线的加速器，嘉宾的判断是该路线在权重存储上具备优势，但受制于上下文缓存。其对缓存的定义为"当前对话的动态知识"，与权重中固化的知识相对；该部分内存规模常超过权重本身，且随使用动态增长、事先不可预知。

技术落点在于 Transformer 结构的拆分：前馈层在大批量条件下受算力约束，注意力层在长上下文条件下受内存约束。嘉宾将两类层焊接于同一架构称为该结构的固有代价，单一芯片难以同时优化两者，合理路径为异构分置。

其对长对话质量衰减的机理解释为：缓存本身为前文的精确表示、不损失信息，衰减来自训练侧的分布——模型训练以较短对话为主，长上下文虽有覆盖但非核心能力。

四、模型侧的剩余效率空间

数据层面，嘉宾将互联网定性为一次性数据补贴，高质量文本约 30 万亿 token，放宽标准约 300 万亿，且已被反复训练。其提出的一项判断为：随机用户的交互反馈已不具价值，中位模型能力已超过随机人类样本，当前需求转向专家偏好。

下一阶段的效率来源为强化学习环境：给定可验证的困难任务与进展度量，环境本身构成数据。其以支出结构佐证——前沿实验室在数据采购上的支出比重下降，在环境构建上的支出比重上升。其推论为：通往通用能力的路径可能是持续堆叠专用能力直至覆盖完整，必要条件为任务可验证。

对"当前效率最低环节"的判断具体且可检验：算力扩展本身效率较高，当代模型稀疏度已达较高水平，激活密度多低于 10%、前沿模型接近 1%；效率损失集中于注意力及其内存使用，上下文缓存基本未经压缩，按信息熵衡量，当前每 token 数 KB 的存储量高出合理水平一至两个数量级。

五、第二层杠杆：芯片选型与工艺角套利

对先进芯片的分配机制，嘉宾的解读为：供应方将算力等同于权力，若任由支付能力最强的买方取得全部供给，将导致单一客户权力过度积累，故分配具有战略性；此外，交易关系与财务背书构成实际准入门槛。

对非先进芯片，其核心论点为：性能问题实质是定价问题，给定合适价格，任何芯片均具备部署价值。其指出主要竞品芯片的软件生态成熟度较低，反而为外部团队留出优化空间；同时修正称该窗口正在收窄，多家大型买方已公开采购。

其将自身优势归为三项：同时驾驭多种架构的工程能力；无历史包袱条件下的软件栈重建速度；以及在异构服务系统中按比较优势分配负载的运营方式。

在晶圆制造环节，嘉宾提出一项非常规视角：产线良品的性能离散度客观存在，代工方为收敛工艺角付出显著的时间与成本；而若接受更宽的工艺角与更高的废品率，可换取更低的晶粒成本。其判断依据为整体优化目标包含晶粒成本、供给量、电力成本与场地可得性三项。

对半导体板块估值占比高企的担忧，其回应的核心区别在于：上一轮周期的网络设备投资为前置性铺设，需求尚未到达；当前的 token 消费具备即时使用属性，不存在囤积行为。其同时区分了 2023 至 2024 年的短缺——该轮支出以训练为主，训练本身具备前置属性。

六、第三层杠杆：分散场地与可中断电力

嘉宾给出的场地可得性阶梯（推理买方视角）为：吉瓦级项目在美国已基本不可得，百兆瓦级难度上升，十兆瓦级为当前可行边界，兆瓦级供给充裕。据此，市场存在总量可观但高度分散的电力资源，该部分资源对训练集群无价值，因训练默认算力集中。

其判断市场存在认知时滞：多数开发商仍按百兆瓦级地块的逻辑获取资源。液冷技术改变了物理尺度——兆瓦级算力当前约对应八个机柜。

该方案的成本让渡列举清晰：无电力冗余、通常不配备现场发电、多数情况下无冗余网络。据此其预期部分站点可用率降至 95%，并明确表态接受该水平。理由为两项：控制平面可在故障不相关的前提下迁移负载；以及可用率在该区间内对其成本函数呈线性影响。前提条件为异步长时程负载——单次故障导致的重新调度延迟对以小时计的任务不构成实质影响。其向客户提供的取舍条款为：平均吞吐具备竞争力，尾部延迟不作承诺，对价为成本优势。

电力层的延伸逻辑为：若可接受 95%，则在合适价格下亦可接受 80%。间歇性电源与数据中心基载需求的传统矛盾，在其模型下可通过可预测的停机化解——以天或周为单位的中断可通过气象建模提前调度负载。其对该策略的成本前提表述为：芯片单价足够低时，闲置产生的资本成本可以承受。

主持人将该策略概括为拾荒式供给获取，嘉宾确认并说明动机：其不参与与头部实验室的算力竞价，转而聚合分散供给形成规模。其自我定位类比为小型电炉钢厂路径，而非一体化钢厂。

在全球尺度上，其指出算力调度效率构成另一项损失来源：当年出货的数百万颗芯片的实际利用率存疑，相当部分进入不可见的私有池并处于闲置状态。

七、成本下降幅度的推算过程

该数字的来源需如实还原。嘉宾设定的目标状态为人均日消耗一万亿 token，按当前定价对应约 500 万美元。其给出的条件为：单位 token 成本需改善三至六个数量级，压缩至 5000 美元量级方具备客户基础。500 万至 5000 美元的区间对应约一千倍，为其给出区间的下限；上限为六个数量级；未给出时间跨度。其补充的现实参照为，特定尺寸模型的万亿 token 成本已向数万美元量级逼近。

改善来源对应前述三层：软件层（内核适配、批处理策略、并行方案、计算单元填充率，其中缓存压缩单项即有一至两个数量级空间）；硬件层（次优先芯片、按单位成本算力选型、异构混搭、接受更宽工艺角）；电力与场地层（分散站点、砍除冗余、接受较低可用率、使用间歇性电源）。

其引用的经验法则为：成本每下降一个数量级，即产生一个新的产品品类。

八、对硬件格局的判断

嘉宾对领先厂商的表态为短期看多，同时给出一项与市场预期相左的判断：同口径比较近三代产品的单位功耗性能，改善幅度有限；上游制程逐代之间的单位功耗性能变化同样有限。该判断的推论是，次优先制程与最先进制程之间的单位功耗性能差距，小于业内讨论所渲染的水平。

对芯片创业方向，其给出四项供应链约束作为论证前提：晶圆产能、高带宽内存产能、先进封装、电力与场地。其方法论要求为差异化必须建立在"领先厂商难以调整的既有选择"之上，产品定位需在单一维度上尖锐化。其自身判断的攻击点为高带宽内存——该环节产能扩张缓慢，存储厂商受周期性资本开支影响而扩产意愿有限。其团队的对应技术路线为将上下文缓存卸载至闪存，即向更极端的内存层级推进。

对领先厂商不自营 token 业务的解释为：避免与客户竞争，维持多元服务商生态，使任何单一环节的向上整合或转向竞品均可被后续参与者替代。

开源与蒸馏方面，其判断领先三至六个月的溢价当前仍成立，但持续性有限，约束条件为企业部署节奏——多数企业仍停留在更早的模型版本，任何变更均需完整的评估流程。其对能力扩散的判断为不可阻断，差异仅在速度；论据之一为公开代码库中模型生成内容占比的持续上升。

其对终局的表述为"充裕的 token 加上多样的外壳"，定制方式以上下文学习为主而非权重微调。全篇主旨句为：当前将智能体视为咨询成本高昂的专家、仅在遇到难题时调用，该使用方式与技术的成本结构不匹配。
