什么会拖慢AI热潮？Cerebras谈产能约束与巨型芯片创业——TechCrunch精翻（2026-10-14）

TechCrunch，29 分钟 · 2026-10-14 · 原始来源 ↗ · 中文精翻

关键词：token需求；推理成本；AI资本开支；代理安全；AI监管；Cerebras；英伟达；OpenAI

——《What Could Break the AI Boom? Cerebras’ Andrew Feldman Has an Idea | Disrupt 2026》（2026-10-14）中文精翻

要点

  • Feldman把数据中心遭遇的社区阻力归于沟通不足及对AI的恐惧；OpenAI扩大合作规模时，Cerebras缺的是可交付的数据中心容量。
  • 他回忆巨型芯片研发：团队曾连续18个月每月消耗800万美元，首版芯片只撑了8秒就碎裂；团队通过测试和失效分析不断改进，努力将寿命提升到十年。
  • 对AI安全，他主张模型、云、网络与芯片共同设防，也反对把行业前景只讲成灾难。

00:00 AI扩张、数据中心效率与芯片竞争，以及智能体安全开关

主持人：下一场讨论的主题是：AI正变得越来越庞大。模型更大，数据中心更大，芯片更多，用电更多，投入的资金也越来越惊人——这或许正是各位今天来到这里的原因。但这种趋势能无限持续下去吗？我们的下一位嘉宾多年来一直在挑战关于AI计算应当如何运作的一些根本假设。下面请欢迎Cerebras联合创始人兼首席执行官Andrew Feldman，与TechCrunch的Julie Bort展开对谈。

Julie Bort：你好，Andrew。

Andrew Feldman：你好，Julie。

Julie Bort：欢迎来到Disrupt。

Andrew Feldman：谢谢你们邀请我。

Julie Bort：你们今年真是非同凡响。

Andrew Feldman：是重要的一年。

Julie Bort：我先简单介绍一下。Cerebras生产AI系统，采用自己定制的巨型芯片，是速度极快的推理芯片。他还带了一块来给大家展示。你在5月带领公司完成了一次非常成功的IPO，募资55亿美元。你们的大客户包括OpenAI和亚马逊AWS，还有许多新兴云服务商，以及Cognition、Lovable、Block、Figma和制药巨头GSK等客户。

但有一些迹象显示，数据中心建设正在失去支持，至少出资方的支持在减弱。甲骨文的股价受到其大量债务的拖累。一家澳大利亚AI云公司取消了IPO。亚马逊还写了一封措辞恳切的呼吁信，希望美国民众支持数据中心。因此，我们今天要回答的问题，也就是我想请你回答的问题是：AI还能像过去几年那样持续扩大规模吗？

Andrew Feldman：哇，我还有机会点评甲骨文的股票。

［笑声］

Andrew Feldman：这下可不妙。我想说几点。我认为，AI需求正以惊人的速度增长。

Andrew Feldman：你能从最大几家公司的持续增长中看到这一点，也能从规模较小的新进入者令人瞠目的增长中看到这一点，比如Instacart，以及其他许多从零起步、做到惊人规模的公司。

当更多人使用AI，而且使用时间越来越长时，就意味着他们在使用更多算力。而使用更多算力，就意味着必须有地方安置这些计算设备。这个地方就是数据中心。事情并没有那么复杂。我们把设备放进建筑里，而这些建筑需要消耗大量电力。

过去几年，我们这个行业在与当地社区合作方面做得不够好。尤其是在美国，我们这个行业没有像电力和油气行业中的其他企业那样去做。没有与社区合作，没有进行应有的社区沟通，这是一个问题。

另外还有一点，AI领域的一些领军人物，或许就不该让他们公开讲话。

［笑声］

Andrew Feldman：我觉得他们近乎狂热地盯着危险和负面因素，却不告诉人们：也许你们的孙辈这辈子都不会遇到因癌症去世的人。他们让我们的社会有了些恐惧。害怕AI时，你很难知道该把这种恐惧指向哪里，于是人们就把矛头指向了数据中心。

讽刺的是，加拿大、挪威、芬兰、瑞典、冰岛、墨西哥和巴西都在鼓励建设数据中心。包括我们在内的数据中心建设者正在与当地社区合作，而这些社区也欢迎我们入驻。

Andrew Feldman：所以，我想我用了很长一段话来回答这个问题：首先，它在疯狂增长；其次——

Julie Bort：嗯，需求在疯狂——

Andrew Feldman：需求在疯狂增长，但数据中心建设也一样。很多时候，如果一个社区强烈反对，建设者就会转去另一个社区、另一个地点，或者另一个国家。

Julie Bort：AI领域现在还在发生另一件事，那就是效率。我们看到了模型压缩，也看到了像Etched这样的你们的竞争对手，声称自己会更高效。还有一种思路正在兴起：别只是一味增加规模，而要利用好已有的资源。

Andrew Feldman：更高效。

Julie Bort：更高效地利用。所以我的问题是，你赞同这种思路吗？要让我们变得更高效，而不是不断建更多数据中心，需要做些什么？

Andrew Feldman：我认为这两件事并不矛盾。我们需要更多数据中心，但也需要提高所建数据中心的效率。电都用到哪里去了？电力先送到数据中心门口，再输送到机架，在这途中会有一部分损耗。这里就有提高效率的空间。到了机架，交换和通信环节也有提高效率的机会。然后进入计算环节，计算本身也有改进的空间。作为硬件供应商，我们可以努力提高计算效率。模型开发者也可以做得更好，让模型以更高的效率实现相同目标。所有这些必须结合起来，才能取得实质性进展。

我们之所以采用大芯片，其中一个原因就是，在同一块硅片内部传输数据，可以做到极低的能耗。

Andrew Feldman：如果必须把数据移出芯片，耗电量就会增加到数千倍。因此，我们的一项真正优势是：完成同等计算量，我们的耗电量仅为GPU的一小部分。但我认为我们所有人都必须合作。这不能只靠做计算的、做交换机的、做传输交换设备的，或者做数据中心的；还有冷水机组，以及我们的备用发电机，这些都实实在在地消耗电力。

Julie Bort：你有没有特别关注这个领域里的某些技术？比如会想，要是这些人能把问题解决，我们就会采用它？

Andrew Feldman：我认为这里不存在某种单一的万能解法。

Julie Bort：好。

Andrew Feldman：我认为每个环节都有基础性的工作要做。而且，多用电对谁都没有好处，对吧？对我们大多数人来说，数据中心的供电上限就是收入上限。如果我们能在20兆瓦的功率范围内放进更多算力，就能赚更多钱。

Julie Bort：好。如果我没理解错，你的意思是，规模会继续扩大，效率也会继续提高。那么，OpenAI是你们的大客户，Sam Altman和Greg Brockman也是你们的天使投资人。不过，下面就是我事先提醒你会问的那个难题：他们为自己的AI服务档位，或者说GPT-6.1 Sol UltraFast，选择的是英伟达，而不是Cerebras。所以我想问，英伟达似乎是一个很难对付的竞争对手，简直无处不在。

Andrew Feldman：你才发现？

Julie Bort：到底发生了什么？

Andrew Feldman：你才发现？事实证明——

Julie Bort：那次到底是怎么回事？［笑声］

Andrew Feldman：最新消息：英伟达是一家很强悍的公司。我知道各位来TechCrunch Disrupt就是为了听这个。跟他们竞争很难。

Julie Bort：他们确实很强悍。所以，那次究竟发生了什么？怎么——

Andrew Feldman：首先，像Sam和Greg这样的人，以他们在2013、2014、2015、2016年时的财富水平，他们做了数以百计的天使投资，而且每笔金额都不算大。所以，我不认为他们持有我们的股份会对决定产生什么影响。况且，他们投得很早，是在A轮时，那时的世界还不一样。这是第一点。

第二点是，我们拿下了GPT-5.6 Sol的项目，并开始部署，速度达到了每秒750、800个token。那个项目非常成功，因此OpenAI希望下一代能把部署规模大幅扩大。

Julie Bort：嗯。

Andrew Feldman：但我们没有足够的容量满足他们。我们没有那么多数据中心，这就回到了你最初的问题。

Julie Bort：对。

Andrew Feldman：我们与他们的协议是，我们为他们建数据中心，然后把我们的计算设备放进去，再向他们出售token。而我们当时就是没有足够的容量。

Julie Bort：那么，现在双方关系如何？

Andrew Feldman：挺好的。

［笑声］

Andrew Feldman：这是一项规模很大的多年合作。路还很长，我认为目前一切都挺好。

Julie Bort：那么，五年后英伟达还会是AI行业无可争议的芯片之王吗？

Andrew Feldman：你看，英特尔过去十年过得很艰难，但仍然占有相当大的市场份额。

Julie Bort：是。

Andrew Feldman：我认为问题不在于英伟达还会不会很出色，而在于还会有多少家公司同样出色，对吧？这才是有意思的问题。AMD现在的估值已经达到1万亿美元。Arm正在研发非常有意思的芯片。还有Marvell这样的公司，已经完成自身转型，如今在做很有意思的事情，并与谷歌这样的公司建立合作关系。

Andrew Feldman：还有像我们Cerebras这样的公司，可以说是挑战传统架构的领头者。我认为，这个市场足够大，会有许许多多非常成功的公司。

Julie Bort：说到英伟达，几周前它发布了开放智能体安全计划，其中包括一个叫作Sentry的工具。这是一种利用芯片在硬件层面监控并自动关闭失控智能体的方法。听起来，我觉得这个主意非常好。

［笑声］

Julie Bort：不过我也说不准。你怎么看？

Andrew Feldman：这肯定是很好的营销。至于是不是好主意，还得看看，得实际用起来。

Julie Bort：什么——

Andrew Feldman：对吧？我们得看实际效果。我认为，用软件为智能体设置防护机制，能够关闭智能体，而且不只是在供电层面，也能在芯片层面关闭，是明智的做法。现实情况是，那些被越狱的模型，对吧？越狱就发生在英伟达的设备上。因此，他们对这件事感兴趣、觉得它重要，我一点也不意外。尤其是他们作为这个领域的老大，站出来说：有办法管理这件事，我们应该压一压市场上目前存在的恐惧。

Julie Bort：那么，Cerebras也会做类似的事情吗？

Andrew Feldman：我们有很多技术，可以在芯片运行异常时，或者在我们认为上面的软件运行异常时，把芯片关闭。

Julie Bort：啊，这不就是AI紧急关闭开关吗？也就是说，那些担心AI带来末日的人想要这样的开关，监管机构也有点想要，而AI行业去年为此大为不满。这不就是一个紧急关闭开关吗？

11:24 AI安全与监管、晶圆级芯片的研发困境，以及创业中的坚持与取舍

Andrew Feldman：最不懂技术的人，在“关闭开关”这类问题上反而意见最响亮，这一点真是很值得注意，对吧？（笑）对，我们需要政府成员，也需要那些未必处于领导位置的人参与。我的意思是，我们必须携起手来：模型开发公司要发挥领导作用，拥有配套软件的云服务商，以及硬件和基础设施领域的企业，也要带头参与。在网络层，同样有机会控制异常流量。也就是Arista、Juniper和Cisco所构建的那个层面，也可以在那里控制流量。我认为，如果我们真想做出有意义的努力，就不能只靠其中一个环节。

主持人：好，这个说法很合理，也很有意思。不过，我还是要把它叫作关闭开关，我看不出有什么理由不这么叫。

Andrew Feldman：当然可以。

主持人：只不过，它存在于多个层面，也存在于硬件之中。

Andrew Feldman：当然。

主持人：好，我很喜欢这个想法。我有投票权吗？我也不知道自己有没有。既然聊到了“关闭”和“杀死”，你觉得AI真的导致人类死亡的可能性有多大？

Andrew Feldman：你看，我认为，自动驾驶汽车会撞死人吗？会。它们撞死人的频率，会远远低于人类开车导致他人死亡的频率吗？会。我认为，我们会把危险的工作交给机器人。像让你16岁的儿子或女儿开车这样的危险事情，我们会用自动驾驶汽车来替代，安全性会高得多。还有像我爸爸开车这样的危险事情，（笑）我们也会用自动驾驶汽车来替代，那也会更安全。

Andrew Feldman：我认为，我们必须时刻记住，衡量AI或机器人技术的标准，不应该是完美无缺，而应该是我们目前正在采用的替代方案，对吧？交通事故是主要死因之一。因此，只要我们能减少这类事故，机器人技术或AI就不必完美，只需要比现在的做法好得多。

主持人：我不认为在我们孩子这一代的有生之年，会出现某种“终结者”机器。但我确实觉得——

Andrew Feldman：而且它不会带奥地利口音。（笑）有一点我们可以肯定：如果它来了，那不会是阿诺德。

主持人：不会是阿诺德。

主持人：对。不过，也许它们也看过那部电影。

发言者：问题就在这里，AI看过那部电影，所以我们也说不准。

主持人：但我确实认为，硅谷一直在忙着打造终极黑客、终极黑客机器。所以，我担心的是“天网”这样的东西。我担心这些机器能以过去做不到的方式，入侵人类赖以生存的系统。我是在杞人忧天吗？你担心这件事吗？

Andrew Feldman：是的，这是一个真实而且重要的担忧。我认为，就目前而言，随着我们上市，我们已经看到针对我们的攻击发生了变化。我们能够追踪到国家行为体对我们的攻击。我的意思是，当你成为规模更大的上市公司，在世界上更有名气之后，就会成为吸引攻击的磁石。我们确实担心这一点，也担心那些得到AI等技术强化、威力大增的攻击。

Andrew Feldman：我不认为有什么强大的技术，能够避开这样一个难题：当强大的技术落到坏人手里，会发生什么？我认为，你不能创造出前者，又指望没有后者。我们必须承认，这项技术很强大，必须审慎对待，必须对它进行合理监管。同时也要明白，世上确实有坏人，无论他们手里拿的是枪、AI，还是斧头，都可能用来作恶。对此，我们必须谨慎。

主持人：你认为我们需要专门针对AI的法规，还是说我们已经有一套能够应对它的制度框架？

Andrew Feldman：总体来说，我不认为我们已经建立了多少针对AI的制度框架。现在各种诉讼围绕的是文字作品的所有权，以及能不能拿这些作品来训练模型。我认为，我们的法律体系存在一个巨大的缺口，它并没有为AI做好准备。整个法律和监管体系大致都是如此：当技术出现重大的全新创新时，监管体系就必须加速追赶。

主持人：很多站在AI前沿的人，一听到“监管”，或者任何和监管有关的字眼，就会直接把它归为坏事，不想要它，然后竭力反对。所以，听到有人说我们可能确实需要采取一些措施，还挺令人耳目一新的。好，你通过创造一种所有人都认为不可能实现的技术，建立起了一整家公司。我想请你再展示一下那块芯片。它之所以更快、更强大，是因为它更大。这是一整块芯片。

主持人：而且它依然很薄。首先，我想听你讲一个当年的故事：那时候你想说服别人支持你做这件事，但所有人都说不可能。

Andrew Feldman：先交代一下基本情况：这是一整块芯片，面积为46,000平方毫米，是计算机行业历史上最大的芯片。在我们之前，最大的芯片是804平方毫米，或者840平方毫米。所以，它的面积大约是此前任何人造过的芯片的55倍。人们普遍认为它既不可能造出来，又是计算机行业的某种圣杯。这并不是因为越大就一定越好。对于手机或笔记本电脑而言，大显然不是好事，但对于AI任务，大有巨大的优势。它可以容纳更多信息，更快地处理信息，并在更短的时间内给出结果。这就是我们的目标，但几乎所有人都认定它绝不可能成功。

做硬科技有一件很有意思的事：一开始，所有人都说它永远不可能成功。等你做成了，他们又说：“好吧，它确实能运行，但永远不可能量产，制造难度太高了。”然后我们——

主持人：不过，它确实很难制造。

Andrew Feldman：确实很难制造。

主持人：你们当时每个月要烧掉大约800万美元，是吧？

Andrew Feldman：有18个月的时间，我们每个月大约花掉800万美元，却始终解决不了技术问题。作为一家非上市公司，你每隔六周就要开一次董事会。那意味着要开很多次董事会，也意味着有很多忧心忡忡的风险投资人，对吧？他们问：“进展怎么样？”我说：“我还是造不出来。”又烧掉5,000万美元以后，他们再问：“进展怎么样？”我说：“我还是造不出来。”但我们最终做到了。

我们让它实现了量产，然后人们说：“可是你们没有客户。”后来，我们拿下了美国政府的许多客户，他们又说：“好吧，现在你们只有政府客户。”接着，我们与阿拉伯联合酋长国的一家集团达成了一笔主权云交易，在当时属于硅谷历史上规模最大的交易之一。他们又说：“可是你们没有任何前沿模型实验室客户。”后来，我们又拿下了OpenAI。所以，这简直就像打地鼠。他们不停地说，你们没有这个，你们还不够好。

Andrew Feldman：而你就不断击破这些质疑，一次次把它们敲下去。他们说：“好吧，你们拿下了OpenAI，但你们没有超大规模云服务商客户。”然后我们拿下了AWS，现在他们终于安静了。（笑）
